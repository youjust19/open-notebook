# Working with Notes - Capturing What You Learn

A note is a piece of Markdown text in a notebook: something you wrote, or an AI answer you kept. Each note has a title, content, and a badge showing whether it is **Human** or **AI Generated**.

Notes are different from **insights**: insights are generated by transformations and attached to a source, while notes belong to a notebook. See [Notebooks, Sources, Insights, and Notes](../2-CORE-CONCEPTS/notebooks-sources-notes.md).

---

## Creating Notes

### Write one yourself

1. In the notebook's **Notes** column, click **Write Note**.
2. Add a title (optional) and write the content in the Markdown editor.
3. Click **Create Note**.

### Save a chat answer

Under any notebook chat answer, click the **Save to note** icon. The note is created immediately as **AI Generated**, with a title generated from the content by your Transformation Model (or Chat Model). There is no dialog; edit the note afterwards if you want a different title.

### Save an Ask answer

After an Ask answer finishes on the **Ask and Search** page, click **Save to Notebooks**, pick one or more notebooks and click **Save to Notebook**. Each selected notebook gets an **AI Generated** note with the question as its title and the answer as its content.

### Turn an insight into a note

Insights can be copied into a notebook as notes through the API (`POST /api/insights/{insight_id}/save-as-note` with a `notebook_id`). There's no button for this in the UI yet.

---

## Editing and Deleting

- **Edit**: click a note card to open it, change the title or content, and click **Save Note**.
- **Delete**: open the note card's ⋮ menu, choose **Delete Note** and confirm. This can't be undone.
- Deleting a notebook deletes its notes.

---

## Finding Notes in a Notebook

The **Search notes** box at the top of the Notes column filters the notebook's notes as you type. It searches note titles and content in your browser, so it needs no AI model and works for notes that aren't embedded.

- **Words match from the start**: `meet` finds "meeting". Every word you type must match. Case and accents are ignored, so `cafe` finds "Café".
- **Exact phrases**: put them in quotes, for example `"budget review"`.
- **Filters**: `is:ai` or `is:human` for the note type; `modified today`, `yesterday`, `this week`, `last week`, `this month`, `last month` or `last 7 days` for when a note was last edited. Start the date with `created` (`created last week`) to filter on creation date instead. Filters combine with words: `budget is:human this month`.
- **Suggested searches**: the **AI notes**, **My notes**, **Edited today** and **Edited this week** buttons add or remove those filters.
- **Top Hits**: when more than three notes match, the best three are shown first under **Top Hits**. Notes whose title matches rank highest, then more recently edited notes. The rest follow, newest first.
- **Keyboard**: **↑**/**↓** pick a result, **Enter** opens it, **Esc** clears the search.

Matching words are highlighted in the titles and in a short excerpt from each note. To search notes across notebooks, or inside sources, use [Search](search.md).

## Using Notes

- **In notebook chat**: each note has a context icon that switches it between included (full content) and **Not included in chat**. The Notes column's **Context** menu includes or excludes all of them. See [Chat Effectively](chat-effectively.md#choosing-what-the-ai-sees).
- **In search and Ask**: notes are covered by text search (titles and content) and, once embedded, by vector search and Ask. Notes are embedded automatically when saved, if an Embedding Model is set.
- **In podcasts**: notes can be selected as episode content. See [Creating Podcasts](creating-podcasts.md).

Notes can't be used as input to transformations; transformations only run on sources. To work with a long note that way, add its text as a source with **Enter Text**.

---

## Tips

- **Write a short summary at the top** of long notes. It helps you and the model.
- **Clean up saved answers.** AI answers often include filler; trimming them keeps chat context small when the note is included.
- **Keep the notebook description current.** It is sent to the model in every notebook chat, which helps the AI understand what your notes are about.
